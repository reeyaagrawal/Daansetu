
# DaanSetu – Donation Tracking System

DaanSetu is a web-based donation tracking and management system designed to make donation activities more transparent and organized.

## Features

- User Registration and Login
- Campaign Creation and Management
- Online Donation Management
- Donation Receipts
- Donor Dashboard
- Admin Dashboard
- Donation Reports and Analytics
- Contact and Support

## Technology Stack

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Power BI

## Project Structure

DaanSetu/
├── app.py
├── requirements.txt
├── templates/
├── static/
└── README.md

## Installation and Setup

1. Clone the repository:

   git clone https://github.com/reeyaagrawal/Daansetu.git

2. Navigate to the project folder:

   cd Daansetu

3. Install dependencies:

   pip install -r requirements.txt

4. Configure the required environment variables:
   - DAANSETU_SECRET_KEY
   - DAANSETU_DB_PASSWORD

5. Configure your MySQL database and import the required schema.

6. Run the application:

   python app.py

7. Open in your browser:

   http://127.0.0.1:5000
